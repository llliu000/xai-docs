<ApiField name="content" type="object[]" label="输入内容列表" required>

传给模型的输入数组。纯文本可以单独提交。使用参考素材时，支持以下组合，文本均可省略。

| 素材组合 | 条件 |

各子字段的必填条件适用于对应的数组元素。Seedance 2.5 和 2.0 系列的真人参考图和视频须使用平台认可的来源，支持预置虚拟人像、已授权的真人素材以及符合条件的模型原始产物。使用方式见[官方教程](https://console.volcengine.com/ark/region:cn-beijing/docs/video-generation-tutorial)。

<ApiField name="omni_reference_task_type" type="string" label="任务类型引导" defaultValue="auto">

在 2.5 系列全模态任务中指定自动判定、参考生成、编辑或延长，对应 `auto`、`reference`、`edit`、`extend`。

| 值 | 调用约束 |
| --- | --- |
| `auto` | 由模型判定任务类型。如参数与判定结果冲突，可能异步返回 `InvalidParameter.TaskTypeConstraint`。 |
| `reference` | 使用参考素材生成新视频。`ratio`、`duration` 遵守常规规则。 |
| `edit` | 至少一个 4–30 秒的 `reference_video`，`ratio` 必须为 `adaptive`，`duration` 必须为 `-1`。 |
| `extend` | 至少一个 `reference_video`，`ratio` 必须为 `adaptive`。 |

显式指定 `reference`、`edit` 或 `extend` 后，接口在提交时校验对应的参数限制。不符合限制的请求会立即失败，任务不会创建。已经创建的任务仍会根据提示词判断实际类型。实际类型和指定类型不一致时，会异步返回 `InvalidParameter.TaskTypeMismatch`。

</ApiField>

<ApiField name="resolution" type="string" label="视频分辨率" defaultValue="按模型">

| 模型 | 默认值 | 可选值 |

| Seedance 2.5 flash、2.0 fast、2.0 mini | `720p` | `480p`、`720p` |
| Seedance 1.0 pro、1.0 pro fast | `1080p` | `480p`、`720p`、`1080p` |

Seedance 2.5 的 1080p 和 4K 输出，以及 Seedance 2.0 的 4K 输出，均使用 10 bit H.265/HEVC。10 bit 有助于保留色彩渐变和明暗细节。播放失败时，可尝试最新版系统或支持该编码的 VLC、MPV 和 QuickTime Player。

</ApiField>

<ApiField name="duration" type="integer" label="视频时长" defaultValue="2.5 系列为 -1">

按秒设置视频长度。需要整数秒时可使用 `duration`。支持 `frames` 的模型同时收到两个字段时，以 `frames` 为准。

| 模型 | 手动指定 | 自动选择 |
| --- | --- | --- |
| Seedance 2.5 系列 | 4–30 秒，编辑任务除外 | `-1`，也是该系列默认值 |
| Seedance 2.0 系列 | 4–15 秒 | `-1` |
| Seedance 1.0 pro、1.0 pro fast | 2–12 秒 | 不支持 |

2.0 系列及 2.5 系列的非编辑任务设置 `-1` 后，模型会在允许范围内选择整秒时长。2.5 系列的编辑任务只能用 `-1`，输入视频须为 4–30 秒。输出会接近模型选中的原片时长，可能包含小数秒，也可能比原片短约 0.4 秒。

可通过[查询任务](/doubao-video/get-video-generation-task-api)查看结果。响应中的 `duration` 是总帧数除以 24 后向下取整的秒数。例如 97 帧约为 4.04 秒，接口返回 4。生成时长会影响计费。

</ApiField>

<ApiField name="frames" type="integer" label="视频帧数">

以总帧数设置时长，适用于 Seedance 1.0 pro 和 1.0 pro fast，可用于生成小数秒视频。有效值为 29–289 范围内满足 `25 + 4n` 的整数，其中 `n` 为正整数。

选择帧数时，先用目标秒数乘以 24，再从有效值中选取最接近的值。例如 3.2 秒约需 76.8 帧，可传 77 帧，实际时长约为 3.21 秒。同时传入 `duration` 时，以 `frames` 为准。

</ApiField>

<ApiField name="generate_audio" type="boolean" label="生成有声视频" defaultValue="true">

Seedance 2.5 和 2.0 系列支持生成同步声音。设为 `true` 时，模型根据提示词和画面生成匹配的对话、音效或配乐。提示词中的台词可以用双引号标明。设为 `false` 时，生成无声视频。

这些模型生成的有声视频固定使用双声道，输出声道数与输入素材的声道数无关。

</ApiField>

<ApiField name="watermark" type="boolean" label="视频水印" defaultValue="false">

设为 `true` 时，视频右下角会显示 `AI 生成`。设为 `false` 时，生成的视频不带该水印。

</ApiField>

<ApiField name="output_format" type="string" label="输出格式" defaultValue="mp4">

Seedance 2.5 系列支持以下两种输出格式。

| 值 | 使用场景 |
| --- | --- |
| `mp4` | 标准色彩精度，适合浏览器、移动端播放和发布。 |
| `mov` | 为调色、抠像和合成等后期场景保留较高色彩精度。编辑和延长任务可将 MOV 用作输入或输出。 |

MOV 输出使用 H.264 视频、yuv444p 色度采样和 PCM 音频，播放器需要同时支持这些格式。VLC、MPV、ffplay 在 macOS 和 Windows 上均可使用，IINA 适用于 macOS。

</ApiField>

<ApiField name="seed" type="integer" label="随机种子" defaultValue="-1">

Seedance 1.0 pro 和 1.0 pro fast 支持使用整数种子控制随机性，范围为 `-1` 到 `2147483647`。省略字段或传 `-1` 时，由模型随机取值。同一请求使用不同种子会产生不同结果。使用同一种子的结果通常相近，仍可能出现差异。

</ApiField>

<ApiField name="camera_fixed" type="boolean" label="固定摄像头" defaultValue="false">

Seedance 1.0 pro 和 1.0 pro fast 支持此字段，参考图场景除外。设为 `true` 时，平台会将固定机位要求加入提示词，模型可能仍产生运镜。设为 `false` 时，不对机位施加固定要求。

</ApiField>

<ApiField name="return_last_frame" type="boolean" label="返回尾帧" defaultValue="false">

设为 `true` 后，可以通过[查询任务](/doubao-video/get-video-generation-task-api)取得 `content.last_frame_url`。尾帧为 JPEG，像素宽高与视频一致，水印沿用 `watermark`。设为 `false` 时，响应不提供尾帧。

生成连续片段时，可用前一段的尾帧作为后一段的首帧。调用方式见[视频生成教程](https://console.volcengine.com/ark/region:cn-beijing/docs/video-generation-tutorial)。

</ApiField>

<ApiField name="draft" type="boolean" label="样片模式" defaultValue="false" sourceText="控制是否开启样片模式">

仅 Seedance 2.5 支持。设为 `true` 时生成预览，可先确认构图、运镜和主体动作是否符合提示词。样片只能使用 `480p`，其他分辨率会报错。设为 `false` 时直接生成正式视频。

有效期从 `created_at` 起算。2026 年 10 月 28 日 10:00（UTC+8）起创建的样片 ID 有效期为 14 天，此前创建的为 7 天。过期后无法用于正式生成。参数限制和费用见 [Seedance 2.5 样片模式](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh#:~:text=样片模式)。

</ApiField>

<ApiField name="service_tier" type="string" label="服务等级" defaultValue="default">

Seedance 1.0 pro 和 1.0 pro fast 支持服务等级设置。任务提交后，服务等级固定。Seedance 2.5 和 2.0 系列不支持 `flex`。

| 值 | 服务模式 |
| --- | --- |
| `default` | 在线推理，RPM 和并发额度较低，适合需要较快返回的任务。 |
| `flex` | 离线推理，TPD 额度较高，价格为在线模式的 50%，适合能够接受较长等待时间的任务。 |

具体配额见[模型列表](https://console.volcengine.com/ark/region:cn-beijing/docs/model-list)。

</ApiField>

<ApiField name="callback_url" type="string" label="回调地址">

任务状态变化时，方舟会向此地址发送 POST 请求。请求体和[查询任务响应](/doubao-video/get-video-generation-task-api)使用相同的结构。

| `status` | 触发条件 |
| --- | --- |
| `queued` | 任务进入队列。 |
| `running` | 任务开始执行。 |
| `succeeded` | 生成完成。若 5 秒内未收到送达确认，平台会回调三次。 |
| `failed` | 生成失败。若 5 秒内未收到送达确认，平台会回调三次。 |
| `expired` | 排队或执行期间超过 `execution_expires_after`。 |

</ApiField>

<ApiField name="execution_expires_after" type="integer" label="任务超时阈值" defaultValue="172800">

从 `created_at` 起，以秒计量任务可以等待和执行的总时间。默认 172800 秒（48 小时），可配置范围为 3600–259200 秒。到期后系统终止未完成的任务，并将其标为 `expired`。在线和离线模式均可按业务需要设置该时限。

</ApiField>

<ApiField name="priority" type="integer" label="执行优先级" defaultValue="0">

Seedance 2.5 和 2.0 系列支持 0–9 的整数优先级，默认 0。同一接入点内，值较大的任务排在较低优先级的等待任务前。同优先级按提交顺序处理。

例如，两个优先级为 0 的任务还在等待时，随后到达的优先级 6 的任务会排到它们前面。已经执行的任务继续运行。该规则仅作用于当前接入点的队列，离线推理 `flex` 不支持设置优先级。

</ApiField>

<ApiField name="safety_identifier" type="string" label="用户标识">

用来区分终端用户，帮助平台识别可能违反使用政策的请求。为每位用户提供稳定且唯一的英文字符串，最多 64 个字符。可以用用户名、用户 ID 或邮箱的哈希值，避免直接传输原始个人信息。

</ApiField>

<ApiField name="tools" type="object[]" label="工具配置">

Seedance 2.5 和 2.0 系列支持配置可用工具。每个数组元素须指定一个 `type`，启用后由模型根据请求决定实际是否调用。

<div className="ark-api-fields">
<ApiField name="type" type="string" label="工具类型" sourceText="tools.type" required>

支持 `web_search`。开启后，模型可根据提示词判断是否查找商品、天气等实时信息，搜索也可能增加生成时延。

通过[查询任务](/doubao-video/get-video-generation-task-api)读取 `usage.tool_usage.web_search`。值为 0 表示本次生成没有发起搜索。

</ApiField>
</div>

</ApiField>
</div>

## 响应参数

<div className="ark-api-fields">
<ApiField name="id" type="string" label="任务 ID" sourceText="视频生成任务 ID 存在有效期">

创建接口异步返回任务 ID。拿到 ID 后，用[查询视频生成任务](/doubao-video/get-video-generation-task-api)读取状态。生成完成后，可从查询响应的 `content.video_url` 获取产物。

| 任务 | 从 `created_at` 起算的有效期 |
| --- | --- |
| 普通任务 | 7 天 |
| 2026 年 10 月 28 日 10:00（UTC+8）及之后创建的样片任务 | 14 天 |
| 该时间之前创建的样片任务 | 7 天 |

样片 ID 到期后，不能再用于生成正式视频。

</ApiField>
