通过阿里云百炼提交视频生成任务。万相 3.0 支持文本、首帧或首尾帧及参考素材，最长输出 30 秒，帧率为 30 fps。保存返回的 `output.task_id` 并[查询视频生成任务](/ali-video/get-video-generation-task-api)。任务 ID 在 24 小时内有效。

## 请求参数

### 请求头

<div className="ark-api-fields">
<ApiField name="Content-Type" type="string" label="请求格式" sourceUrl={officialUrl} sourceText="Content-Type" required>

固定值为 `application/json`。

</ApiField>

<ApiField name="Authorization" type="string" label="API Key" sourceUrl={officialUrl} sourceText="Authorization" required>

请求头的值为 `Bearer $DASHSCOPE_API_KEY`，其中变量为业务空间和地域对应的百炼 API Key。

</ApiField>
</div>

### Body 参数

<div className="ark-api-fields">
<ApiField name="model" type="string" label="模型名称" sourceUrl={officialUrl} sourceText="wan3.0-video-prime" required>

标准版为 `wan3.0-video`，Prime 版为 `wan3.0-video-prime`。两者能力一致。资源紧张时，部分 Prime 任务可能按标准速率运行并按标准版计费。

</ApiField>

<ApiField name="input" type="object" label="生成输入" sourceUrl={officialUrl} sourceText="输入的基本信息" required>

提供文本提示词、媒体素材或两者。

<div className="ark-api-fields">
<ApiField name="prompt" type="string" label="提示词" sourceUrl={officialUrl} sourceText="文本提示词" required="conditional">

支持中英文字。最多 20000 字符，超出部分会截断。参考模式可用「图1」「视频1」「音频1」等称呼按类别引用素材。仅传提示词时执行文生视频。

</ApiField>

<ApiField name="media" type="array" label="媒体素材" sourceUrl={officialUrl} sourceText="媒体素材数组" required="conditional">

与 `prompt` 至少提供一项。数组元素包含 `type` 和 `url`。参考模式下，图片、视频和音频各自按数组中出现的顺序从 1 编号，供提示词引用。

<div className="ark-api-fields">
<ApiField name="type" type="string" label="素材类型" sourceUrl={officialUrl} sourceText="媒体素材类型" required>

| `type` | 用途及数量限制 |
| --- | --- |
| `first_frame` | 将一张图严格用作视频开头。最多 1 张。 |
| `last_frame` | 将一张图严格用作视频结尾。最多 1 张，和首帧一起传入。 |
| `reference_image` | 图像参考，最多 10 张。 |
| `reference_video` | 视频参考，最多 5 段，总时长最多 15 秒。 |
| `reference_audio` | 音频参考，最多 5 段，总时长最多 15 秒。 |
| `file` | 参考文件，最多 1 个。与 `link` 二选一。 |
| `link` | 公开网页，最多 1 个。与 `file` 二选一。 |

</ApiField>

<ApiField name="url" type="string" label="素材地址" sourceUrl={officialUrl} sourceText="媒体素材URL" required>

公网素材使用 HTTP 或 HTTPS。图像、视频、音频和文件还可使用百炼上传接口签发的临时 OSS URL。图像另支持 `data:<MIME 类型>;base64,<数据>`。

| 素材 | 文件和尺寸限制 |
| --- | --- |
| 图像 | JPEG、JPG、无透明通道的 PNG、BMP、WebP。宽和高均为 240–8000 px，长宽比最多 8:1，每张最大 20 MB。 |
| 视频 | MP4 或 MOV。单段 1–15 秒，全部视频合计最多 15 秒。至少 16 fps，宽和高均为 240–4096 px，长宽比最多 8:1，单段最大 100 MB。 |
| 音频 | WAV 或 MP3。单段 1–15 秒，全部音频合计最多 15 秒，每段最大 15 MB。 |
| 文件 | DOCX、DOC、XLSX、XLS、PPTX、PPT、PDF、TXT、KEY、PAGES、NUMBERS、MD。每个最大 100 MB。PDF、DOCX、DOC、PPTX、PPT、KEY 和 PAGES 还受 50 页上限约束。 |
| 网页 | 可直接访问的公开 HTTP 或 HTTPS 页面，例如新闻或博客。 |

</ApiField>
</div>

</ApiField>
</div>

</ApiField>

<ApiField name="parameters" type="object" label="生成参数" sourceUrl={officialUrl} sourceText="视频处理参数">

设置输出规格和音频、水印等选项。

<div className="ark-api-fields">
<ApiField name="resolution" type="string" label="分辨率" sourceUrl={officialUrl} sourceText="分辨率档位" defaultValue="1080P">

支持 `1080P`、`720P`、`480P`。

</ApiField>

<ApiField name="ratio" type="string" label="宽高比" sourceUrl={officialUrl} sourceText="生成视频的宽高比" defaultValue="adaptive">

`adaptive` 根据素材比例和生成意图自动选择。也可指定 `21:9`、`16:9`、`4:3`、`1:1`、`3:4` 或 `9:16`。视频延长使用 `adaptive`。

</ApiField>

<ApiField name="duration" type="integer" label="输出时长" sourceUrl={officialUrl} sourceText="生成视频的时长" defaultValue="5">

以秒计。无视频输入时支持 2–30 的整数。传入视频时，输入视频与输出视频的累计时长限 30 秒。使用 `-1` 时由模型选择时长。

</ApiField>

<ApiField name="audio" type="boolean" label="是否输出音频" sourceUrl={officialUrl} sourceText="输出视频是否包含音频" defaultValue="true">

`true` 生成有声视频，`false` 生成无音轨视频。两种设置价格相同。

</ApiField>

<ApiField name="seed" type="integer" label="随机种子" sourceUrl={officialUrl} sourceText="随机种子">

取 `-1` 或 0–2147483647 内的整数。省略或传 `-1` 时自动选择。相同种子生成的结果仍可能有差异。

</ApiField>

<ApiField name="prompt_extend" type="boolean" label="提示词改写" sourceUrl={officialUrl} sourceText="prompt_extend" defaultValue="true">

开启后会对提示词进行智能改写，可能增加耗时。传入 `file` 或 `link` 时须为 `true`。

</ApiField>

<ApiField name="watermark" type="boolean" label="是否添加水印" sourceUrl={officialUrl} sourceText="是否添加水印" defaultValue="false">

设为 `true` 时为输出加上水印。

</ApiField>
</div>

</ApiField>

### 素材组合

| 模式 | 传参规则 |
| --- | --- |
| 文生视频 | 仅使用 `input.prompt`。 |
| 首帧生视频 | 使用一个 `first_frame`，可附带 `prompt`。 |
| 首尾帧生视频 | 同时使用 `first_frame` 与 `last_frame`，可附带 `prompt`。 |
| 参考生视频 | 参考图、参考视频、参考音频可以组合。 |
| 参考文件或网页 | `file` 与 `link` 二选一，可和参考素材组合，`prompt_extend` 须为 `true`。 |
| 视频编辑 | 提交 `reference_video`，在 `prompt` 中描述要修改的内容。 |
| 视频延长 | 提交 `reference_video`，在 `prompt` 中说明延长方向，`ratio` 设为 `adaptive`。 |

首帧和尾帧模式的媒体数组只容纳帧图，参考素材、文件和网页使用各自的模式。
