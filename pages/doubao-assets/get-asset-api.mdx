按素材 ID 查询单个素材，获取处理状态、访问地址和错误信息。入库后可查询此接口确认素材是否已变为 `Active`。

账号级限流为 100 QPS。

## 鉴权

本接口支持以下鉴权方式，详情见 [素材资产 API 鉴权](https://docs.volcengine.com/docs/ark/private-virtual-avatar-library-guide-preview?lang=zh)。

- API Key 鉴权适用于本文的素材网关示例。前往 [API Key 管理](https://ark.volcengine.com/region:cn-beijing/apiKey) 获取长效 API Key。直连官方素材接口使用 AK/SK 签名，前往 [Access Key 管理](https://console.volcengine.com/iam/keymanage) 获取访问密钥。

<div className="ark-api-fields">

## 响应参数

接口业务字段位于 `Result` 中。`ResponseMetadata` 包含请求元信息。

<div className="ark-api-fields">
<ApiField name="AssetType" type="string" label="素材类型" sourceUrl={officialUrl}>

`Image` 表示图像，`Video` 表示视频，`Audio` 表示音频。

</ApiField>

<ApiField name="CreateTime" type="string" label="创建时间" sourceUrl={officialUrl}>

资源创建的时间。

</ApiField>

<ApiField name="Error" type="object" label="错误信息" sourceUrl={officialUrl}>

素材处理失败时返回。具体处理错误及建议见此接口的官方说明。

<div className="ark-api-fields">
<ApiField name="Code" type="string" label="错误码" sourceUrl={officialUrl} sourceText="Error.Code">

失败原因的机器可读标识。

| 错误码 | 排查方向 |
| --- | --- |
| `FaceMismatch` | 素材中的人脸与参考或授权人脸不一致。 |
| `TranscodingFailed` | 检查媒体能否正常解码和转码。 |
| `ContentRestricted` | 素材未通过内容安全审核。 |
| `DownloadFailed` | 检查服务端能否访问素材 URL。 |
| `TypeMismatch` | 检查实际文件类型是否与 `AssetType` 一致。 |
| `FormatUnsupported`、`FormatUndetectable` | 检查文件是否损坏，以及实际编码和格式是否受支持。 |
| `AudioTrackRequired`、`AudioTrackForbidden` | 检查音轨是否符合素材要求。 |
| `DurationTooShort`、`DurationTooLong` | 检查媒体时长。 |
| `WidthTooSmall`、`HeightTooSmall`、`WidthTooLarge`、`HeightTooLarge` | 检查素材宽高。 |
| `AspectRatioTooSmall`、`AspectRatioTooLarge` | 检查宽高比。 |
| `FileSizeTooLarge` | 检查文件大小。 |
| `PixelCountTooSmall`、`PixelCountTooLarge` | 检查总像素数。 |
| `FpsTooLow`、`FpsTooHigh` | 检查视频帧率。 |
| `InputTextSensitiveContentDetected`、`InputImageSensitiveContentDetected`、`InputVideoSensitiveContentDetected`、`InputAudioSensitiveContentDetected` | 对应的输入内容未通过安全审核。 |
| 上述 `Input…SensitiveContentDetected` 错误码带 `.PolicyViolation` 后缀 | 对应内容受到版权或政策限制。 |
| `ModerationServiceErrorUploadFailed` | 审核服务暂不可用或上传审核失败，可重新提交素材。 |
| `InternalError` | 素材处理发生内部异常。 |

</ApiField>

<ApiField name="Message" type="string" label="错误信息" sourceUrl={officialUrl} sourceText="Error.Message">

错误的说明，用于定位处理失败的原因。

</ApiField>
</div>

</ApiField>

<ApiField name="GroupId" type="string" label="所属素材组 ID" sourceUrl={officialUrl}>

该素材关联的素材组标识。

<ApiField name="Id" type="string" label="素材 ID" sourceUrl={officialUrl}>

</ApiField>

<ApiField name="Moderation" type="object" label="内容审核" sourceUrl={officialUrl}>

</ApiField>

<ApiField name="Name" type="string" label="素材名称" sourceUrl={officialUrl}>

素材名称，最多 64 个字符。

<ApiField name="ProjectName" type="string" label="所属项目" sourceUrl={officialUrl}>

## 输入示例

未配置站点基础地址时，将 `ARK_ASSET_BASE_URL` 设置为支持 Bearer 鉴权的素材网关地址，通过 `ARK_API_KEY` 提供凭证。直连火山方舟官方素材接口 `https://ark.cn-beijing.volcengineapi.com` 时，使用 AK/SK 签名。

```sh title="cURL"
curl --fail-with-body --request POST \
  --url "${base_url}/api/v3/asset/?Action=GetAsset&Version=2024-01-01" \
  --header "Authorization: Bearer $ARK_API_KEY" \
  --header 'Content-Type: application/json' \
  --data-raw '{
  "Id": "asset-20261122123100-demo",
  "ProjectName": "default"
}'
```
