按组类型、组 ID 或名称查询素材组。列表支持游标和页码两种分页方式，未指定分页参数时使用游标。

账号级限流为 10 QPS。

## 鉴权

本接口支持以下鉴权方式，详情见 [素材资产 API 鉴权](https://docs.volcengine.com/docs/ark/private-virtual-avatar-library-guide-preview?lang=zh)。

- API Key 鉴权适用于本文的素材网关示例。前往 [API Key 管理](https://ark.volcengine.com/region:cn-beijing/apiKey) 获取长效 API Key。直连官方素材接口使用 AK/SK 签名，前往 [Access Key 管理](https://console.volcengine.com/iam/keymanage) 获取访问密钥。

## 请求参数

### Body 参数

<div className="ark-api-fields">
<ApiField name="Filter" type="object" label="过滤条件" sourceUrl={officialUrl} required>

指定素材组类型，可结合名称和素材组 ID 缩小查询范围。

<div className="ark-api-fields">
<ApiField name="GroupType" type="string" label="素材组类型" sourceUrl={officialUrl} sourceText="Filter.GroupType" required>

`Public` 为公共素材组，`LivenessFace` 为活体真人素材组，`AIGC` 为虚拟人像素材组。

</ApiField>

<ApiField name="GroupIds" type="string[]" label="素材组 ID 列表" sourceUrl={officialUrl} sourceText="Filter.GroupIds">

限制查询范围的素材组标识列表。

</ApiField>

<ApiField name="Name" type="string" label="素材组名称" sourceUrl={officialUrl} sourceText="Filter.Name">

按名称筛选，输入上限为 64 个字符。

</ApiField>
</div>

</ApiField>

<ApiField name="NextToken" type="string" label="翻页凭证" sourceUrl={officialUrl}>

首次游标请求省略此字段。查询下一页时原样传回上一页返回的 `NextToken`。不能和 `PageNumber`、`PageSize` 混用。

</ApiField>

<ApiField name="MaxResults" type="integer" label="每页记录数" sourceUrl={officialUrl} defaultValue="10">

游标分页的每页上限，范围为 1–100。首次或后续请求省略时为 10。不能和页码分页参数混用。

</ApiField>

<ApiField name="SortBy" type="string" label="排序字段" sourceUrl={officialUrl} defaultValue="CreateTime">

支持 `CreateTime` 和 `UpdateTime`。

</ApiField>

<ApiField name="SortOrder" type="string" label="排序顺序" sourceUrl={officialUrl} defaultValue="Desc">

`Asc` 表示升序，`Desc` 表示降序。

</ApiField>

<ApiField name="ProjectName" type="string" label="所属项目" sourceUrl={officialUrl} defaultValue="default">

资源所在的项目。若资源属于非默认项目，传入实际项目名。

</ApiField>

<ApiField name="PageNumber" type="integer" label="页码" sourceUrl={officialUrl}>

从 1 开始。使用页码时不能同传 `NextToken` 或 `MaxResults`。当 `PageSize × PageNumber` 超过 10000 时，改用游标分页。

</ApiField>

<ApiField name="PageSize" type="integer" label="每页记录数" sourceUrl={officialUrl}>

页码分页时的每页大小，范围为 1–100。当 `PageSize × PageNumber` 超过 10000 时，改用游标分页。

</ApiField>

## 输入示例

未配置站点基础地址时，将 `ARK_ASSET_BASE_URL` 设置为支持 Bearer 鉴权的素材网关地址，通过 `ARK_API_KEY` 提供凭证。直连火山方舟官方素材接口 `https://ark.cn-beijing.volcengineapi.com` 时，使用 AK/SK 签名。

```sh title="cURL"
curl --fail-with-body --request POST \
  --url "${base_url}/api/v3/asset/?Action=ListAssetGroups&Version=2024-01-01" \
  --header "Authorization: Bearer $ARK_API_KEY" \
  --header 'Content-Type: application/json' \
  --data-raw '{
  "Filter": {
    "GroupType": "AIGC"
  },
  "MaxResults": 10,
  "ProjectName": "default"
}'
```
