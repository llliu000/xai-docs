## 鉴权

本接口支持以下鉴权方式，详情见 [Gemini 官方鉴权说明](https://aistudio.google.com/docs/api-key)。

- API Key 鉴权。前往 [Google AI Studio API Key 管理](https://aistudio.google.com/apikey) 获取 API Key。

## Carbon 模型限制

| 项目 | 限制 |
| --- | --- |
| 上下文窗口 | 输入、思考和输出共享 1,048,576 个令牌 |
| 直接非流式 REST | 每次调用最多生成 32,768 个令牌 |
| 流式 REST | 每次流式调用最多生成 65,536 个令牌 |
| 推理级别 | `low`、`medium`（默认）、`high` |
| 上下文缓存 | 仅支持隐式缓存 |

[Gemini 4 Carbon 官方指南](https://aistudio.google.com/docs/whats-new-gemini-4-carbon?hl=ja&codelanguage=rest&generate-content=true)

## 长输出与续写

需要跨过单次输出上限时，可从流式请求开始，设置高于 65,536 的 `maxOutputTokens`，且不得超过上下文窗口减去输入令牌数。收到 `CONTINUATION` 后，保留原始输入和已接收的输出，把该候选的 `continuationToken` 放入下一次请求。按顺序拼接各段的正文，直到收到终止原因。续写请求维持或提高原有总预算。若返回 `MAX_TOKENS` 并附带令牌，须先提高总预算才可继续。

流式连接中断时，使用最近的续写检查点恢复，丢弃该检查点之后尚未确认的片段，避免重复追加文本。[Google 长输出指南](https://aistudio.google.com/docs/long-decode?generate-content=true)
