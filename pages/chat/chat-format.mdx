按顺序提交 `messages` 对话消息，由模型生成下一条回复。接口支持多轮文本对话、图片等多模态输入、结构化 JSON、工具调用和流式输出，具体能力取决于模型。[OpenAI 官方接口参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)

<ApiField name="refusal" type="string" label="拒绝说明" sourceUrl={officialUrl} sourceText="refusal">

<ApiField name="prompt_cache_breakpoint" type="object" label="显式提示词缓存断点" sourceUrl={officialUrl} sourceText="prompt_cache_breakpoint">

## 响应参数

### 非流式响应

文本回复位于 `choices[].message.content`。若候选返回 `tool_calls`，客户端按调用记录执行工具，并把原始助手消息和工具结果加入下一次请求的 `messages`。

<div className="ark-api-fields">

<ApiField name="id" type="string" label="完成对象 ID" sourceUrl={officialUrl} sourceText="id">

本次聊天完成对象的唯一标识。

</ApiField>

<ApiField name="object" type="string" label="对象类型" sourceUrl={officialUrl} sourceText="object">

普通 JSON 响应固定为 `chat.completion`。

</ApiField>

<ApiField name="created" type="integer" label="创建时间" sourceUrl={officialUrl} sourceText="created">

Unix 时间戳，单位为秒。

</ApiField>

<ApiField name="model" type="string" label="模型" sourceUrl={officialUrl} sourceText="model">

实际生成本次回复的模型。

</ApiField>

<ApiField name="choices" type="object[]" label="候选回复" sourceUrl={officialUrl} sourceText="choices">

包含候选序号、模型消息和结束原因。流式数据块的结构见下方。

<div className="ark-api-fields">

<ApiField name="index" type="integer" label="候选序号" sourceUrl={officialUrl} sourceText="index">

当前候选在候选列表中的索引。

</ApiField>

<ApiField name="message" type="object" label="模型消息" sourceUrl={officialUrl} sourceText="message">

通常含 `role: "assistant"` 和 `content`。工具调用、音频或拒答也可通过对应字段返回。

<div className="ark-api-fields">

<ApiField name="role" type="string" label="消息角色" sourceUrl={officialUrl} sourceText="role">

固定为 `assistant`。

</ApiField>

<ApiField name="content" type="string 或 null" label="回复正文" sourceUrl={officialUrl} sourceText="content">

助手的文本内容。工具调用时可能为 `null`。结构化 JSON 输出也通过此字段返回文本。

</ApiField>

<ApiField name="refusal" type="string 或 null" label="拒绝说明" sourceUrl={officialUrl} sourceText="refusal">

模型拒绝生成时可能返回此说明。

</ApiField>

<ApiField name="tool_calls" type="object[] 或 null" label="工具调用" sourceUrl={officialUrl} sourceText="tool_calls">

每项返回 `id`、`type` 和与工具类型对应的内容。函数调用用 `function.name` 和 `function.arguments`，后者是 JSON 字符串。自定义工具用 `custom.name` 和 `custom.input`。客户端校验参数、执行工具，再通过 `role: "tool"` 和对应 `tool_call_id` 回传结果。

</ApiField>

<ApiField name="function_call" type="object 或 null" label="旧版函数调用" sourceUrl={officialUrl} sourceText="function_call">

已弃用。旧响应包含 `name` 和 JSON 字符串 `arguments`。

</ApiField>

<ApiField name="annotations" type="object[]" label="引用注释" sourceUrl={officialUrl} sourceText="annotations">

网页引用的 `type` 为 `url_citation`，`url_citation` 包含链接、标题和引用在文本中的起止索引。

</ApiField>

<ApiField name="audio" type="object 或 null" label="音频响应" sourceUrl={officialUrl} sourceText="audio">

支持的输出可含音频 `id`、Base64 `data`、转写文本 `transcript` 和过期时间 `expires_at`（Unix 秒）。

</ApiField>

</div>

</ApiField>

<ApiField name="finish_reason" type="string" label="结束原因" sourceUrl={officialUrl} sourceText="finish_reason">

`stop` 表示自然结束或命中停止序列，`length` 表示达到生成上限，`tool_calls` 表示请求调用工具，`content_filter` 表示部分内容被过滤，`function_call` 为旧版函数结束原因。

</ApiField>

<ApiField name="logprobs" type="object 或 null" label="输出对数概率" sourceUrl={officialUrl} sourceText="logprobs">

支持时，通过 `content` 或 `refusal` 返回每个令牌的 `token`、`logprob`、UTF-8 `bytes` 和 `top_logprobs`。

</ApiField>

</div>

</ApiField>

<ApiField name="metadata" type="object 或 null" label="元数据" sourceUrl={officialUrl} sourceText="metadata">

### 流式响应

`stream: true` 时，服务端通过 SSE 发送多个 `chat.completion.chunk` 对象。同一次响应的块共用 `id`，按 `choices[].index` 分组并按到达顺序追加 `delta.content`。工具调用参数也可能分片，应按候选和工具调用的 `index` 拼接，收齐后再解析。[OpenAI 流式响应参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/streaming-events)

| 字段或标记 | 读取方式 |
| --- | --- |
| `choices[].delta` | 本块新增的角色、文本、工具调用或其他内容。可为空对象。 |
| `choices[].finish_reason` | 生成中通常为 `null`。结束时可返回 `stop`、`length`、`tool_calls` 等。 |
| `usage` | 开启 `stream_options.include_usage` 后，最后一个 JSON 块以 `choices: []` 返回汇总用量。 |
| `data: [DONE]` | 流结束标记。 |
